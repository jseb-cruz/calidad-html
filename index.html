Cómo aplicar ISO/IEC 25010, ISO/IEC/IEEE 12207 y CMMI en una empresa

Guía de trabajo con plantillas editables. Cada grupo parte de su empresa ficticia y construye, sesión a sesión, su Dossier de Calidad.

Regla de oro

Un modelo no se implementa «completo»: se implementa lo necesario para el contexto, con evidencia.

Cómo se usa

Haga clic en cualquier celda para escribir. Todo se guarda solo en este navegador. Use el mismo archivo y el mismo equipo durante todo el módulo.

Los datos son suyos

Los ejemplos de NovaSoft Andina (clínicas odontológicas, Scrum, datos de salud) son solo referencia. Inventen cifras coherentes y justifíquenlas.

Qué pregunta responde cada modelo

ModeloPreguntaQué le entrega a la empresaPlantillas
ISO/IEC 25010¿Qué significa que mi software sea de calidad?Características medibles de producto y calidad en usoP2, P3
ISO/IEC/IEEE 12207¿Qué procesos debe tener mi ciclo de vida?Procesos adaptables (tailoring)P5, P6
CMMI¿Qué tan madura es mi organización para ejecutarlos?Niveles de madurez y áreas de prácticaP7, P8

Ruta recomendada para una empresa pequeña

  1. 25010 primero: definir qué calidad promete el producto.
  2. 12207 adaptado: fijar los procesos mínimos para lograrla.
  3. CMMI nivel 2: consolidar gestión del proyecto y evidencias.
  4. Nivel 3 en adelante: solo si el negocio lo justifica.

Atajo: si el mayor dolor es la previsibilidad de los proyectos, empiece por CMMI nivel 2. Declare la edición que usa (25010 de 2011 o 2023; CMMI v1.3, 2.0 o 3.0): la lógica es la misma. CMMI no se «certifica», se evalúa.
